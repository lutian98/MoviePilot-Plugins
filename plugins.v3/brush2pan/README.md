# 刷流直传 115（Brush2Pan）

MoviePilot 插件：刷流下载完成的影片 → 识别/筛选 → 经 CD2 直传 115 指定目录，并按 TMDB 重命名。

## 流程

1. 每 60 秒读取下载器中指定保存路径下已完成的种子
2. 文件名解析 → TMDB 识别
3. 口径筛选：
   - 只收电影（不收剧集）
   - 只收 1080p / 2160p
   - 不收蓝光原盘（BDMV / m2ts / ISO）
   - 只排除 5.1 声道（7.1 / Atmos / TrueHD 等不再排除）
   - 默认最小 300MB
4. 通过 CD2 gRPC `CreateFolder` → `CopyFile` 上传（CD2 服务端直接读取本地文件并写入 115，插件不搬运文件）
5. 复制完成后 `RenameFile` 为 `片名 (年份) - 1080p.mkv`
6. 状态保存在插件数据目录

## 配置

| 字段 | 说明 |
|---|---|
| 启用插件 | 总开关 |
| 演练模式 | 默认开：只记录计划，不复制 |
| CD2 gRPC 地址 | 例如 `cd2:19798`（按你的部署填写） |
| CD2 API Token | CD2 中创建的 API 令牌，需读写 + 本地列目录权限 |
| 本地源路径 | CD2 视角的刷流目录，按你的目录填写 |
| 115 目标目录 | 按你的目录填写 |
| 下载器保存路径过滤 | 只处理该路径下完成的种子 |
| 最小体积 | 默认 300MB |
| TMDB API Key | 留空则用 MoviePilot 内置 |

## 实现说明

- 上传完全由 CD2 完成，插件只负责识别、筛选、发起复制与重命名
- `grpcurl` 二进制首次运行时下载到插件数据目录
- 依赖：MoviePilot 自带的 `requests`、`qbittorrent-api`
